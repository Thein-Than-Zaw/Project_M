## Engineering changes

ChatService/Controller extend optional replyToId while preserving old Send/Message constructors for existing callers. Message projection adds dynamic quote, per-user reactions, deletion/version/hidden metadata. Conversation changeVersion plus bounded /api/chat/messages snapshots reconcile old-message mutations after missed WS events/reconnect without treating mutation version as the send sequence. Hidden stubs/removed IDs and per-message versions block stale live payload resurrection. Mutation invalidations use the existing authenticated chat queue, with own-only hide and both-member delete/reaction; no new STOMP commands or reaction inbox/sound events. HTTP mutation endpoints require cookie/CSRF/active membership and never accept a client-selected actor. Home unread and Notification target resolution agree with hidden/deleted state.

V23 adds same-space reply FK, deletion/version/hash and conversation change version; hash backfill + INSERT trigger use PostgreSQL core SHA256/canonical jsonb intent. V24 reaction and V25 hidden tables each use one member/message PK and scoped composite FKs. V1–V22 unchanged. Hash retains retry identity, not cleartext payload. Reply/reaction hydration batches bounded pages; hidden snapshot membership is fetched in one batch, not one query per row. Existing catalog files are not deleted when a gift message is scrubbed.

chat.html/js/css implement action/confirmation/error/pending, reply draft/quotes, emoji pressed states, pills and cleanup. Small-screen picker wraps to3 columns under360px; actions are keyboard labelled. Chat read acknowledgements stop while gift/message/inbox dialogs or full-page call obscure the conversation. Incoming call closes the new action dialog before opening its full-page view. Notification Settings volume/browser controls and taller call video remain preserved.
